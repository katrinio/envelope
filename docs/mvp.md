# MVP — Envelope feature

## Основное

* [x] Пользователь видит список своих конвертов.
* [x] Каждый конверт показывает:

  * [x] название;
  * [x] текущую сумму;
  * [x] целевую сумму;
  * [x] процент прогресса;
  * [x] сегментированный progress bar;
  * [x] короткий статус (`€X to go`, `almost there`, `goal reached ✓`).
* [x] Если конвертов нет, отображается понятный empty state.
* [x] UI следует `docs/design_manifest.md`.

## Изменение суммы

* [x] У каждого конверта есть кнопки `[−]` и `[+]`.
* [x] По нажатию `[+]` появляется компактное поле ввода суммы пополнения.
* [x] По нажатию `[−]` появляется компактное поле ввода суммы списания.
* [x] Поле не содержит browser spinner/stepper arrows.
* [x] Значение вводится вручную с клавиатуры.
* [x] После подтверждения текущая сумма конверта обновляется.
* [x] Нельзя уменьшить текущую сумму ниже `0`.
* [x] После изменения суммы UI обновляет процент, progress bar и статус.

## Создание конверта

* [x] После существующих конвертов отображается плитка `+ NEW ENVELOPE`.
* [x] По нажатию плитка превращается в компактную форму создания.
* [x] Для нового обычного конверта можно указать:

  * [x] название;
  * [x] целевую сумму.
* [x] Название обязательно.
* [x] Целевая сумма должна быть больше `0`.
* [x] После сохранения новый конверт появляется в списке.
* [x] Создание можно отменить без изменений.

## Редактирование конверта

* [x] У каждого конверта есть ненавязчивое меню `•••`.
* [x] В меню доступно действие `Edit`.
* [x] Для обычного конверта можно изменить:

  * [x] название;
  * [x] целевую сумму.
* [x] Редактирование происходит локально внутри плитки или в небольшом компактном overlay, без отдельной страницы.
* [x] Изменения можно сохранить или отменить.

## Удаление конверта

* [x] В меню `•••` доступно действие `Delete`.
* [ ] Перед удалением требуется подтверждение.
* [ ] В подтверждении явно указано, что удаление конверта не влияет на реальные деньги пользователя.
* [x] После подтверждения конверт удаляется физически из базы.
* [x] Soft delete не используется.

## Pillow / emergency fund

* [x] Конверт подушки поддерживается как специальный тип конверта, а не через проверку имени.
* [x] Его целевая сумма вычисляется как множитель от зарплаты пользователя.
* [x] Для MVP используется значение `2 × salary`.
* [x] При изменении зарплаты целевая сумма Pillow пересчитывается автоматически.
* [x] В UI видно, что цель вычисляемая, например: `2 × monthly salary`.
* [x] Целевую сумму Pillow нельзя редактировать как обычное число.
* [x] Архитектура не должна зависеть от строки `"Pillow"` или `"Emergency Fund"`.

## Не входит в MVP

* [x] Не добавлять транзакционную историю.
* [x] Не добавлять категории расходов.
* [x] Не добавлять банковские интеграции.
* [x] Не добавлять прогнозирование даты достижения цели.
* [x] Не добавлять рекомендации между несколькими конвертами.
* [x] Не добавлять wishlist.
* [x] Не добавлять полноценную авторизацию.
* [x] Не добавлять drag-and-drop сортировку.
* [x] Не добавлять отдельный глобальный edit mode страницы.
