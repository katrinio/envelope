# Текущий MVP

Сейчас приложение помогает одному пользователю видеть долгосрочные накопления в виде отдельных конвертов. Это первая спокойная и простая версия без попытки сразу решить все задачи личных финансов.

## Что уже работает

- пользователь с именем и зарплатой;
- создание конвертов с целью, приоритетом и текущей суммой;
- просмотр всех конвертов пользователя;
- изменение накопленной суммы через `+` и `−`;
- удаление конверта;
- точный процент прогресса и сегментированный индикатор;
- короткий статус: сколько осталось, цель почти достигнута или уже закрыта;
- серверная HTML-страница и JSON API.

Главная страница находится по пути:

```text
/users/{user_id}/envelopes/page
```

Интерфейс остаётся компактным и почти монохромным. Каждый конверт выглядит как небольшое карманное электронное устройство, но без буквальной стилизации под ретро-игру. Подробное направление описано в [`design_manifest.md`](design_manifest.md).

## Основные API-маршруты

- `POST /users/{user_id}/envelopes` — создать конверт.
- `GET /users/{user_id}/envelopes` — получить конверты пользователя.
- `GET /envelopes/{envelope_id}` — получить один конверт.
- `PATCH /envelopes/{envelope_id}/current-amount` — заменить текущую сумму.
- `DELETE /envelopes/{envelope_id}` — удалить конверт.

## Чего пока нет

На этом этапе нет авторизации, истории операций, рекомендаций, прогнозирования, списков желаний и специальных правил расчёта финансовой подушки. Суммы меняются напрямую, а удаление физически убирает запись из базы.

Это намеренное ограничение: сначала важно сделать понятной базовую работу с целями и накоплениями.
