# MVP — Envelope

Текущий MVP уже включает основные сценарии приложения:

- [x] Серверная страница с общим заголовком пользователя и зарплаты.
- [x] Разделы Long-Term Savings и Monthly Spending с сохранением выбранной вкладки.
- [x] Создание, редактирование и окончательное удаление конвертов.
- [x] Изменение текущей суммы с проверкой неотрицательного баланса.
- [x] Financial Pillow с целью `зарплата × 2` и автоматическим пересчётом.
- [x] История операций: регулярность, редактирование и удаление записей.
- [x] Инсайты по накоплениям и прогрессу целей.
- [x] Изменение имени и зарплаты пользователя.
- [x] Перестановка конвертов с сохранением порядка.
- [x] Monthly Spending: доступный пул денег и список планируемых трат.
- [x] Локальные формы, компактные меню и подтверждение удаления.

Интерфейс остаётся серверным, без авторизации и frontend-фреймворка. Дизайн и тон сообщений описаны в [`design_manifest.md`](design_manifest.md).

## Пока не входит

Не реализованы полноценная авторизация, категории и регулярность расходов, банковские интеграции и расширенная аналитика. Эти возможности можно добавлять отдельно, не меняя базовую модель текущего MVP.
