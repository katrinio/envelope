# Хранение данных

По умолчанию приложение использует SQLite. Локальный путь — `data/app.db`, а в Docker база находится в `/data/envelope.db`. Путь можно изменить через `DATABASE_URL`.

Схемой управляет Alembic. Для нового окружения достаточно выполнить:

```bash
poetry run alembic upgrade head
```

## Основные данные

- `User` — имя и месячная зарплата пользователя.
- `Envelope` — цели долгосрочных накоплений, включая специальную Financial Pillow.
- `Contribution` — пополнения и списания с датой и признаком регулярности.
- `SpendingPool` и `PlannedSpending` — доступные деньги и запланированные траты для Monthly Spending.

Конверты принадлежат пользователю и удаляются физически. Баланс конверта поддерживается историей операций. Цель Financial Pillow вычисляется из текущей зарплаты и не хранится как отдельный источник истины.

## Миграции

В репозитории поддерживается одна актуальная baseline-миграция. После изменения моделей создаётся новая миграция, затем проверяется состояние:

```bash
poetry run alembic current
poetry run alembic check
```

В тестах допустимо создавать схему напрямую, но обычный запуск приложения и деплой используют Alembic.
