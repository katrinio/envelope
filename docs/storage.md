# Хранение данных

По умолчанию приложение использует SQLite-базу:

```text
data/app.db
```

Путь можно заменить через переменную окружения `DATABASE_URL`. Например:

```bash
DATABASE_URL=sqlite:///data/local.db poetry run uvicorn src.main:app --reload
```

Локальные файлы из `data/` не хранятся в Git.

## Модели

### User

Пользователь хранит внутренний `id`, внешний `userId`, имя и зарплату. У одного пользователя может быть несколько конвертов.

### Envelope

Конверт содержит:

- владельца (`user_id`);
- название;
- текущую сумму;
- целевую сумму;
- положительный приоритет.

Суммы хранятся целыми числами. Отрицательные значения запрещены, а целевая сумма должна быть больше нуля.

Конверт связан с пользователем внешним ключом. При удалении пользователя его конверты также удаляются. Сам конверт удаляется окончательно — soft delete сейчас не используется.

## Миграции

Схемой базы управляет Alembic. Применить все миграции:

```bash
poetry run alembic upgrade head
```

Проверить текущую версию:

```bash
poetry run alembic current
```

После изменения ORM-моделей нужна отдельная миграция. Автоматическое `create_all` остаётся удобным для тестов, но обычный запуск приложения должен опираться на Alembic.
